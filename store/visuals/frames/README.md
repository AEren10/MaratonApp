# Mağaza görselleri

1. Ham ekran görüntülerini `shots/` içine koy (dosya adları `slides.js`'te).
2. `bash store/visuals/frames/render.sh` → `out/ios/01-08.png` (1320×2868), `out/android/01-08.png` (1440×2560).
3. Play: `out/play/feature-1024x500.png`, `out/play/icon-512.png`.

Başlıklar `slides.js`'te; kaynak `store/aso-2026-10.md` bölüm 6. Eksik görüntü varsa kare "bekleniyor" yazısıyla çıkar — yüklemeden önce kontrol et.
