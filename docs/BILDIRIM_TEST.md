# Bildirim cihaz testi (gercek iPhone, preview/production build)

1. Temiz kurulum -> kayit -> kurulumda "Bildirimlere izin ver": iOS izin penceresi cikmali; Ayarlar > Maraton > Bildirimler acik.
2. Ayarlar > Bildirim'de gunluk hatirlatma saatini ~30 dk sonraya al (kisiye ozel +-20 dk kayma var), ana sayfayi ac, uygulamayi ARKA PLANA at (onde banner bilerek yok) -> o pencerede TEK bildirim, metinde bugunun duraklari.
3. Bildirime dokun (arka plan): Plan ekrani acilmali; tekrar metinliyse Tekrar oturumu. Ana ekran DEGIL.
4. Ayni testi uygulama tamamen kapaliyken yap: soguk acilista yine hedef ekran; sonra kapatip IKONDAN ac -> ana ekran.
5. Gunluk hatirlatmayi KAPAT, uygulamayi kapat-ac -> o saatte bildirim GELMEMELI. Bugun calisma kaydet -> 22:00 seri uyarisi GELMEMELI.
6. Izin reddedilmis cihazda ayarlardan hatirlatma ac -> "Izin Gerekli", anahtarlar kapali kalir.
7. Cikis yap -> hatirlatma saatini bekle: HIC bildirim yok. Widget'lar bos (0).
8. Baska hesapla gir: ana sayfa, seri, program/tasinan duraklar, rutinler, "hallettim" tikleri, kesif ipuclari ve widget'lar ilk hesabinkini GOSTERMEMELI.
9. Hesabi sil (SIL yaz): giris ekranina donmeli, bildirim gelmemeli, ayni e-postayla giris "hatali bilgi" vermeli. (FK migration'i uygulandiktan sonra, paylasilmis sorusu olan hesapla da dene.)
10. Ucak modunda cikis yap, uygulamayi kapat-ac -> giris ekrani (eski hesap geri gelmemeli).
11. Sunucu push'u (streak_risk / weekly_summary) dokununca -> Plan / Haftalik ozet.
